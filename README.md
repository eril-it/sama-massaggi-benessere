# SAMA Massaggi e Benessere

Sito web mobile-first per SAMA Massaggi e Benessere.

## Struttura iniziale

- `index.html` — home page
- `trattamenti.html` — tutti i trattamenti in un'unica pagina
- `chi-sono.html` — presentazione
- `contatti.html` — contatti e posizione
- `style.css` — stile condiviso
- `script.js` — interazioni
- `assets/` — immagini e logo

Design di riferimento: concept **3C · Story / Reel inspired**, con palette coordinata al logo SAMA.
